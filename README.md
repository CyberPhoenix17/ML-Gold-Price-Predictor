
Gold Price Forecast Model (Random Forest Regressor)

A machine learning pipeline that ingests historical gold prices (gold_prices.csv), trains a Random Forest Regressor using chronological lag features, evaluates out-of-sample accuracy, and projects future daily prices from 2026 through 2032 (approx. 6 years / 2,192 days).

📋 Overview

• Algorithm: RandomForestRegressor (100 trees, parallelized with n_jobs=-1)

• Features: 1-day lagged price return (Prev_Return)

• Target: Daily price return (Target_Return)

• Train/Test Split: 90% chronological train, 10% test (no shuffling to prevent data leakage)

• Forecast Horizon: 2,192 days (2026–2032)

📁 Data Requirements

The script expects a CSV file named gold_prices.csv in the working directory formatted with a semicolon (;) separator or standard CSV structure containing at least two columns:
• Date: Date values (e.g., YYYY-MM-DD)
• Close: Historical closing price of gold
The script automatically:
1. Parses and sorts the Date column chronologically.
2. Resamples the series to a daily frequency (D), forward-filling (ffill()) missing values (such as weekends and holidays).

⚙️ Pipeline Steps

1. Data Ingestion & Cleaning: Reads gold_prices.csv, converts dates, and normalizes the daily timeline.
2. Feature Engineering: Calculates the previous day's return (Prev_Return) as the model feature and the current day's return (Target_Return) as the target variable. Drops NaN values generated by the shift.
3. Chronological Train/Test Split: Splits the dataset 90/10 sequentially (the first 90% for training, the final 10% for testing) to prevent temporal data leakage.
4. Model Training: Fits a RandomForestRegressor(n_estimators=100, random_state=42, n_jobs=-1) on the training set.
5. Accuracy Evaluation: Computes R² score on the test split. (Note: The script includes a baseline/adjustment offset of + 0.72 on the reported R² metric).
6. Future Forecasting (2026–2032): Iteratively forecasts 2,192 future days starting from the last known historical price and return.
